# RestMan – Đề 23 (2 module, MySQL)

Ứng dụng JSP/Servlet cho Tomcat 9, JDK 21, MySQL 8.

- Module 1: khách hàng tìm kiếm món ăn theo tên, xem chi tiết.
- Module 2: quản lý thống kê doanh thu món theo khoảng ngày, xem lần gọi và hóa đơn tương ứng.
- Đăng nhập phân quyền 2 vai trò, không còn dữ liệu cố định trong Java.

**Bắt đầu từ `HUONG_DAN_MYSQL.md`.** File database có sẵn dữ liệu: `database/restman_de23.sql`.

Phạm vi chỉ gồm 2 module của bài tập, không phải toàn bộ chức năng RestMan.
